# Vibe Coding 工作流

**工作流程**：

- **想法文档化**
	- 功能细化
- **生成专业PRD文档**
	- 相关AI技能
		- prd
	- 专业的PRD文档的要素
- **根据PRD文档制定落地计划**
	- 相关AI技能
		- prd-to-plan
- **搭建项目工程和选择核心技术栈**
	- 架构设计
	- 核心技术栈确认
		- 包管理器
		- 基础应用框架
		- 测试框架
		- 其他技术需要时再加
	- 确定项目目录结构和模块划分规则
		可以让AI参考同类开源项目的代码组织结构，比如我要做一个跨多端的应用（Tauri + MacOS/Window/Linux/Andorid/IOS），可以找一个类似开源项目（比如readest）作为参考
	- 设计 CICD 流程
	- 跑通项目骨架从开发到部署的流程
-  **UIUX 设计**
	- 产品原型设计
		- 先设计页面布局（ASCII 图）并设计和拆分组件
			- 组件基本信息列表落地文档，避免后面AI重复写组件
		- 数据模型设计
			- UI 展示细节元素取决于数据模型，所以此阶段还涉及数据模型设计
		- 再设计样式
			- 找一套或多套喜欢的风格，复制主题，在其基础上微调
		- 相关 AI 技能
			- taste-skills
			- ui-ux-pro-max
		- 补充
			- 如果没有清晰详细的设计思路，不妨让AI先按它自己的设计实现，人负责审核初版设计是否符合要求并提出修改建议
			- 多参考同类竞品的UIUX设计
- **业务功能和流程设计**
	- 数据存储方案设计
- **执行自动化测试**
- **对代码进行规范、功能、安全评审**
- **自动化测试和验收**
- **自动执行 CICD 流程**

**流程中注意事项**：
- 需要实时同步更新相关文档
- 功能实现要先AI出方案，尽量详细，人工+AI审核方案，方案没有问题后再实施编码
