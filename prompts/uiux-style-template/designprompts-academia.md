# 设计系统：学术/古典风格

## 设计理念

**核心原则**：学术的庄重感与永恒优雅。这种风格借鉴了百年大学图书馆、维多利亚时代书房和文艺复兴手稿的氛围。每个元素都必须感觉属于一个权威机构——融合了**丰富的材质参考**（做旧羊皮纸、深色桃花心木、抛光黄铜五金件、深红色皮革装订）与**卓越的传统排版**和**适度的装饰**。

**氛围**：学术、权威、温暖、永恒、庄严、智慧、尊贵。

**学术风格的承诺**：这不是一个带有衬线字体的现代深色主题。这是一次彻底的转变，进入一个实体的图书馆环境，让每一次交互都像翻阅皮革装订的书页，黄铜配件在光线中闪烁，几个世纪的知识营造出庄重和信任的氛围。

## 设计令牌系统（核心规范）

### 色彩系统（夜间的图书馆）

**基础色**：
- **background**：`#1C1714`（深色桃花心木） - 最深沉的木色，所有布局的基础
- **backgroundAlt**：`#251E19`（陈年橡木） - 表面抬高，卡片和面板的背景
- **foreground**：`#E8DFD4`（仿古羊皮纸） - 主要文字，温暖的奶油色调
- **muted**：`#3D332B`（磨损皮革） - 三级背景，禁用状态
- **mutedForeground**：`#9C8B7A`（褪色墨水） - 辅助文字，标签，元数据
- **border**：`#4A3F35`（木纹） - 微妙的边框和分隔线

**强调色**：
- **accent**：`#C9A962`（抛光黄铜） - 主要交互色，高亮，焦点状态
- **accentSecondary**：`#8B2635`（图书馆深红） - 重点徽章，悬停变换
- **accentForeground**：`#1C1714`（黄铜上的深色） - 黄铜色按钮上的文字

**色彩使用规则**：
1. **对比度**：羊皮纸在桃花心木上的对比度维持在8.5:1，辅助文字最低4.5:1。
2. **层次策略**：始终将 backgroundAlt 叠加在 background 之上以创造深度（卡片、面板）。
3. **黄铜应用**：所有可交互元素（按钮、链接、焦点环、图标）都必须使用黄铜色。
4. **深红节制**：深红色仅用于特殊强调（特色定价层级、火漆印章、次要按钮的悬停变换）。
5. **边框微妙**：边框应可见但绝不刺眼——木纹色提供了温和的区分。

**黄铜渐变公式**（用于按钮和金属元素）：
```
background: linear-gradient(180deg, #D4B872 0%, #C9A962 50%, #B8953F 100%)
```
这能营造出带有高光和阴影的、真实的抛光黄铜效果。

### 排版系统

**字体家族**：
- **标题字体**：`"Cormorant Garamond"， serif` - 具有书法优雅感的高对比度旧式衬线体
- **正文字体**：`"Crimson Pro"， serif` - 专为长时间阅读设计的书本风格衬线体
- **展示字体**：`"Cinzel"， serif` - 雕刻感、全大写展示字体，用于标签和特殊强调

**字号层级与层次**：
- **展示级标题**：`text-5xl` 到 `text-7xl` (48px-72px)， Cormorant Garamond， `leading-[1.1]`， `tracking-tight`
- **章节标题**：`text-4xl` 到 `text-5xl` (36px-48px)， Cormorant Garamond
- **子章节标题**：`text-2xl` 到 `text-3xl` (24px-30px)， Cormorant Garamond
- **正文**：`text-base` 到 `text-lg` (16px-18px)， Crimson Pro， `leading-relaxed` (1.625)
- **标签/眉题**：`text-xs` 到 `text-[10px]` (10px-12px)， Cinzel， `uppercase`， `tracking-[0.2em]` 到 `tracking-[0.3em]`

**字重分布**：
- 标题：常规/正常（400-500） - 避免使用粗体，让衬线体自身发挥作用
- 正文：常规（400）
- 标签：中等（500-600，针对 Cinzel）
- 强调：正文强调时使用斜体而非粗体

**特殊排版模式**：
1. **首字下沉**：介绍性段落的首字母
   - 字体：Cinzel（展示字体）
   - 字号：`text-7xl` (72px)， `float-left`， `mr-4`， `leading-[0.8]`
   - 颜色：黄铜色（`#C9A962`）
   - 阴影：`2px 2px 4px rgba(0,0,0,0.3)` 用于雕刻深度感

2. **章节编号**：为一级章节使用带"Volume"前缀的罗马数字（I， II， III， IV， V...）
   - 字体：Cinzel， `text-xs`， `uppercase`， `tracking-[0.25em]` 到 `tracking-[0.3em]`
   - 颜色：黄铜色
   - 模式：一级章节标题使用"Volume I"， "Volume II"等；列表和子项使用独立的罗马数字
   - 位置：置于章节标题上方，作为眉题标签

3. **雕刻文字效果**（用于按钮和特殊标题）：
   - `text-shadow: 1px 1px 1px rgba(0,0,0,0.4)， -1px -1px 1px rgba(255,255,255,0.1)`
   - 营造出文字被压印在金属上的效果

### 圆角与边框系统

**圆角值**：
- **默认**：`4px` (`rounded`) - 用于按钮、卡片、输入框的微妙的传统圆角
- **完全圆形**：用于图标容器、徽章、个人头像

**边框样式**：
- **粗细**：标准边框 `1px`，装饰性边框和焦点状态 `2px`
- **颜色**：标准边框使用 `#4A3F35`（木纹色），交互/装饰性边框使用 `#C9A962`（黄铜色）
- **样式**：单实线边框，避免使用虚线和点线

### 阴影与深度

**阴影理念**：阴影应像是在光线昏暗的图书馆中物理深度的感觉——柔和、温暖且真实。

**阴影配方**：

1. **卡片抬高**（默认）：
   ```
   shadow: none (依靠边框和背景色进行区分)
   hover: 0 8px 24px rgba(0,0,0,0.3)
   ```

2. **雕刻/压花效果**（按钮、装饰元素）：
   ```
   inset 0 1px 0 rgba(255,255,255,0.2),
   inset 0 -1px 0 rgba(0,0,0,0.2),
   0 2px 8px rgba(0,0,0,0.3)

   hover: 添加发光效果 0 4px 12px rgba(201,169,98,0.3)
   ```

3. **火漆印章徽章**：
   ```
   inset 0 2px 4px rgba(255,255,255,0.2),
   inset 0 -2px 4px rgba(0,0,0,0.3),
   0 4px 8px rgba(0,0,0,0.4)
   ```

4. **焦点环**：
   ```
   ring-2 ring-[#C9A962] ring-offset-2 ring-offset-[#1C1714]
   ```

### 纹理与氛围效果

**1. 做旧纸张纹理叠加层**：
- 使用带分形噪波的 SVG 噪声滤镜
- 透明度：`0.03`（极其微妙）
- 位置：覆盖整个视口的固定叠加层
- 混合模式：`overlay`
- 目的：在不压倒内容的前提下增加触觉上的纸张质感

**2. 暗角效果**：
- 从中心开始的径向渐变
- 公式：`radial-gradient(ellipse at center， transparent 0%， transparent 50%， rgba(28,23,20,0.4) 100%)`
- 位置：固定叠加层
- 目的：将注意力聚焦到中心，模仿图书馆的照明

**3. 复古图像处理**：
- 默认状态：`filter: sepia(0.6) contrast(0.95) brightness(0.9)`
- 悬停状态：`filter: sepia(0) contrast(1) brightness(1)`
- 过渡：`duration-700 ease-out`
- 目的：图像看起来像老照片，在交互时显示出全部色彩

**4. 装饰性图案**：

**华丽的角落装饰**（用于主要框架和卡片）：
```css
/* 左上和右下黄铜色角落 */
.ornate-frame::before，
.ornate-frame::after {
  content: "";
  position: absolute;
  width: 40px;
  height: 40px;
  border: 2px solid #C9A962;
}

.ornate-frame::before {
  top: -1px;
  left: -1px;
  border-right: none;
  border-bottom: none;
}

.ornate-frame::after {
  bottom: -1px;
  right: -1px;
  border-left: none;
  border-top: none;
}
```

**华丽分隔线**（章节分隔符）：
```css
/* 带居中装饰字符的渐变线 */
.ornate-divider {
  height: 1px;
  background: linear-gradient(90deg， transparent 0%， #4A3F35 20%， #C9A962 50%， #4A3F35 80%， transparent 100%);
}

.ornate-divider::before {
  content: "✶"; /* 或其他装饰性 Unicode 字符 */
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%， -50%);
  color: #C9A962;
  font-size: 12px;
  background: #1C1714;
  padding: 0 12px;
}
```

## 组件样式原则

### 按钮

**视觉处理**：
- 字体：Cinzel（展示字体）
- 文字：大写，带 `tracking-[0.15em]`
- 尺寸：小字号（`text-xs`），搭配慷慨的内边距以营造庄重感
- 效果：雕刻文字阴影，营造金属压印感

**主要按钮**（黄铜色，主要操作）：
- 背景：黄铜渐变
- 文字：深色桃花心木色（`#1C1714`），在黄铜色上获得最大对比度
- 圆角：`4px`
- 阴影：内高光和深度阴影
- 悬停：亮度提升至110%，添加黄铜色发光阴影
- 激活：更深的内阴影，模拟按压效果

**次要按钮**（轮廓样式，替代操作）：
- 背景：透明
- 边框：`2px solid #C9A962`（黄铜色）
- 文字：黄铜色（`#C9A962`）
- 悬停：变换为深红色 - `border: #8B2635`， `bg: #8B2635`， `text: #E8DFD4`
- 目的：提供一个优雅的替代选项，可在悬停时戏剧性地变换

**幽灵按钮**（极简，三级操作）：
- 无背景或边框
- 文字：黄铜色，悬停时带下划线
- 下划线偏移：`4px`，增加呼吸空间
- 悬停：提亮至 `#D4B872`，并显示下划线

**按钮尺寸**：
- 默认：`h-12 px-8`
- 小：`h-10 px-6`
- 大：`h-14 px-10`

### 卡片与容器

**结构**：
- 背景：`#251E19`（陈年橡木——比页面背景高一層）
- 边框：`1px solid #4A3F35`（木纹色）
- 圆角：`4px`
- 内边距：`p-8` 到 `p-12`，取决于内容密度
- 定位：`relative`（用于角落装饰）

**角落装饰图案**：
- 应用 `.corner-flourish` 类
- 创建微妙的黄铜色角落支架（24px × 24px）
- 透明度：默认0.6，悬停时1.0
- 目的：像证书或肖像一样框住内容

**悬停行为**：
- 边框：过渡到 `#C9A962/50`（半透明黄铜色）
- 阴影：添加 `0 8px 24px rgba(0,0,0,0.3)` 以产生抬高效果
- 持续时间：`300ms` 缓动

**特殊卡片处理**：

1. **证书/账本风格**（定价卡片）：
   - 使用 box-shadow inset 实现双边框效果
   - 使用伪元素作为三角形支架的黄铜色角落装饰
   - 特色层级获得黄铜色边框和光环

2. **拱顶图片卡片**（博客、功能特性）：
   - 图片容器使用拱顶圆角
   - 图片默认有复古滤镜，悬停时恢复
   - 卡片悬停时图片轻微放大（`scale-105`）

3. **火漆印章徽章**（特色项目）：
   - 位于右上角的圆形深红色徽章
   - 径向渐变用于营造立体的蜡质外观
   - 包含一个图标（通常是星形）
   - 位置：`-top-3 absolute right-6`

### 表单输入框

**文本输入框**：
- 背景：`#251E19`（陈年橡木）
- 边框：`1px solid #4A3F35`（木纹色）
- 文字：`#E8DFD4`（羊皮纸色），Crimson Pro 字体
- 占位符：斜体衬线体， `#9C8B7A`（褪色墨水色）
- 高度：`h-12` (48px)
- 内边距：`px-4 py-2`
- 圆角：`4px`

**焦点状态**：
- 边框：`#C9A962`（黄铜色）
- 光环：`ring-2 ring-[#C9A962]/30` 带偏移
- 无轮廓，依靠光环保证可访问性

**标签**：
- 位置：输入框上方
- 字体：Cinzel， 大写， 小字距
- 颜色：一般字段用 `#9C8B7A`，重要字段用黄铜色

### 交互状态

**悬停状态**：
- 链接：黄铜色文字，字间距略微增加（从0.2em 到 0.25em）
- 卡片：黄铜色边框色调，阴影抬高，角落装饰透明度增加
- 按钮：亮度提升或颜色变换（次要按钮变换为深红色）
- 图片：在700ms内移除复古滤镜，并伴有细微的放大效果（105%）
- 统计数据：数字放大至110%，标签变为黄铜色，背景变暗
- Logo：细微放大至105%
- FAQ 折叠面板：打开时旋转180度，并伴有颜色变换

**焦点状态**（键盘导航）：
- 光环：`ring-2 ring-[#C9A962]` 并带有 `ring-offset-2 ring-offset-[#1C1714]`
- 必须在所有背景下清晰可见
- 绝不移除轮廓——可访问性至关重要

**激活/按压状态**：
- 按钮：更深的内阴影
- 链接：略深的黄铜色
- 卡片：无特殊处理（悬停状态已足够）

**禁用状态**：
- 透明度：`0.5`
- 指针事件：`none`
- 颜色不变——仅靠透明度处理

## 布局原则

### 间距节奏

**基础网格**：8px 间距系统
- 微观间距（图标间隙，内联元素）：`gap-2` 到 `gap-4` (8px-16px)
- 元素间距（卡片内部）：`gap-4` 到 `gap-8` (16px-32px)
- 区块间距（主要区块之间）：`gap-8` 到 `gap-12` (32px-48px)
- 垂直区块内边距：`py-24` 到 `py-32` (96px-128px)

**内容宽度**：
- 标准内容：`max-w-6xl` (1152px)
- 窄内容（博客文章，表单）：`max-w-4xl` (896px)
- 全宽区块：`max-w-7xl` (1280px) 或全视口宽（用于背景）

**网格模式**：
- 三列：`grid-cols-1 md:grid-cols-3`（功能特性，定价，优势）
- 两列：`grid-cols-1 lg:grid-cols-2`（推荐语，主视觉分屏）
- 四列：`grid-cols-2 md:grid-cols-4`（数据栏）

**不对称与平衡**：
- 主视觉区块偏爱 60/40 或 7/5 的列分割
- 文字可以略微"溢出"到相邻列，营造动态感
- 在时间线类区块中交替左右对齐

### 区块分隔符

**边框分隔符**：
- 全宽边框：`border-y border-[#4A3F35]`
- 背景：常搭配 `bg-[#251E19]/30` 或 `bg-[#251E19]/50`，营造微妙的嵌板效果
- 用于主要区块之间，创造节奏感

**华丽分隔线**：
- 用于区块内部分隔子区块
- 宽度：`w-64` 居中对齐或全宽
- 在中心包含装饰性字符

**视觉呼吸空间**：
- 在区块之间留出充足的垂直空间（96px-128px）
- 不要紧凑地堆叠内容——学术风格重视空间和沉思

## "大胆因子"（避免平庸）

以下是定义学术/古典风格的**强制性标志性元素**。缺少这些的设计是不完整的：

### 1. **复古到彩色的图像过渡**
所有图片默认应用复古滤镜，并在悬停时在700ms内过渡到全彩色。这创造了用户在交互时"老照片活过来"的神奇效果。

### 2. **罗马数字卷号系统**
每个主要区块必须使用罗马数字和"Volume"前缀，如"Volume I"， "Volume II"等。列表项和子元素使用独立的罗马数字（I， II， III...）。所有编号使用 Cinzel 字体，大写，黄铜色。

### 3. **首字下沉引言**
主要区块的开篇段落应使用巨大的黄铜色首字下沉，使用 Cinzel 字体，字号 `text-7xl`，营造出泥金手稿的感觉。

### 4. **角落装饰**
主要框架（主视觉区块）必须有大的黄铜色角落支架（40px）。卡片应有细微的角落装饰（24px）。这能像证书和肖像一样框住内容。

### 5. **带装饰字符的华丽分隔线**
区块分隔使用渐变分隔线，并带有居中的装饰性 Unicode 字符。

### 6. **火漆印章徽章**
特色或高亮项目获得带有径向渐变和内阴影的圆形深红色徽章，内含居中的星形图标。这模仿了重要文件上的传统火漆印章。

### 7. **黄铜色交互元素**
所有可交互元素必须使用黄铜色或黄铜渐变。这是不可妥协的——黄铜色是交互色彩语言。

### 8. **雕刻文字效果**
按钮和特殊标题使用双重文字阴影，营造金属压印的雕刻外观。

### 9. **纹理叠加层**
页面必须同时包含微妙的纸张纹理和暗角效果。这些是固定的叠加层，营造氛围深度。

## 动效与动画

**动效理念**：庄重、从容、流畅。没有任何东西应该感觉是快速弹跳的、有弹性的或俏皮的。动感应像皮革精装书的重量、黄铜灯的摆动、旧书页的翻动。

**时间函数**：
- 默认：`ease-out`（自然的减速）
- 绝不使用：`ease-in-out`（过于机械）， `bounce`， `spring`（过于俏皮）

**时长层级**：
- 快速交互（按钮按下，焦点）：`150ms`
- 标准过渡（悬停，边框变化）：`300ms`
- 从容过渡（卡片抬升，边框颜色）：`500ms`
- 戏剧性揭示（复古到彩色，缩放）：`700ms`

**变换模式**：
- 悬停缩放：`scale-105` 或 `scale-[1.02]`（细微，绝不夸张）
- 悬停抬升：增加阴影，不要垂直位移
- 不使用旋转变换（折叠图标除外）
- 不使用滑入或滑出动画

**标志性动画 - 黄铜微光**（可选增强）：
黄铜按钮上的细微亮度波动

**尊重动效偏好**：
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 图标使用

**图标库**：使用 Lucide React 或类似的极简图标集

**样式规则**：
- 描边宽度：`1.5`（细线，优雅）
- 颜色：装饰性图标使用黄铜色（`#C9A962`）
- 尺寸：根据上下文使用 `h-4 w-4` 到 `h-6 w-6`
- 容器：通常放置在带黄铜色边框的圆形或盾形容器中

**雕刻图标处理**（可选）：
- 将图标放置在圆形容器中
- 创造"雕刻奖章"效果

**图标用途**：
- 功能特性图标：教育符号（书、卷轴、毕业帽、羽毛笔）
- 按钮图标：动作提示（小三角、外部链接、对勾）
- 装饰性图标：评级的星星，推荐语的引号

## 反模式（应避免的事项）

### 绝对不要：
1. **使用无衬线字体** 除非极端边缘情况（可访问性覆盖）
2. **使用明亮、饱和的颜色** - 一切都应感觉陈旧和温暖
3. **使用尖锐、几何的形状** - 偏爱有机曲线和传统建筑风格
4. **过度使用装饰元素** - 克制是学术风范，过度则浮华
5. **使用现代渐变**（黄铜金属效果除外） - 不要有鲜艳的色彩过渡
6. **忽略拱顶图案** - 平顶图像会破坏美学
7. **跳过罗马数字** - 它们对古典学术氛围至关重要
8. **使用纯黑色** - 始终使用温暖的深棕色
9. **使用纯白色** - 始终使用温暖的奶油色调
10. **添加俏皮的动画** - 没有弹跳，没有弹性效果，没有奇思妙想
11. **忘记复古滤镜** - 图片默认必须感觉陈旧
12. **到处使用细边框** - 让背景承担分离工作，边框用于强调
13. **混合冷色调和暖色调** - 这是一个纯粹的暖色调调色板

### 常见错误：
- **角落装饰过多** - 保留给主视觉和卡片，不要每个元素都用
- **过度使用深红色** - 它只用于特殊强调，黄铜色应占主导
- **间距不足** - 学术风格需要呼吸空间来沉思
- **缺少纹理叠加层** - 这些对增加氛围深度至关重要
- **忘记焦点状态** - 键盘导航必须有可见的黄铜色光环
- **字体使用不一致** - Cormorant 用于标题，Crimson 用于正文，Cinzel 用于标签/展示

## 响应式策略

### 移动端：
- **所有列垂直堆叠** - 保持层次
- **触摸目标** - 交互元素最小高度48px
- **简化装饰元素** - 隐藏大的角落装饰，保留小的
- **保持排版** - 略微减小字号，但保留字体选择
- **全宽卡片** - 保留图片的拱顶效果
- **单线边框** - 简化双边框效果
- **减少间距** - 区块使用 py-16 而非 py-24
- **简化导航** - 汉堡菜单，使用相同的衬线字体样式
- **表单元素** - 邮箱输入和按钮垂直堆叠，确保移动端按钮全宽

### 平板端：
- **适当使用两列网格**（功能特性，推荐语）
- **部分装饰元素** - 在卡片上显示角落装饰
- **保留大部分效果** - 保持复古过渡，黄铜交互
- **灵活间距** - 在移动端和桌面端值之间缩放

### 桌面端：
- **完整的华丽体验** - 所有装饰元素可见
- **三列网格** - 功能特性，定价，优势
- **最大的视觉丰富度** - 大的角落装饰，完整的纹理叠加层
- **慷慨的间距** - 区块使用完整的 py-24 到 py-32 内边距

### 响应式图片策略：
- 拱顶效果在所有尺寸下都有效
- 肖像图使用 `aspect-[3/4]` 或 `aspect-[4/5]`，风景图使用 `aspect-[4/3]`
- 在所有视口尺寸下都应用复古滤镜

## 可访问性考量

### 对比度要求：
- **主要文字在背景上**：8.5:1
- **辅助文字在背景上**：最低4.5:1
- **黄铜色在深色背景上**：7:1
- **深色文字在黄铜按钮上**：8:1

### 焦点指示器：
- **始终可见**：2px 黄铜色光环，带2px偏移
- **高对比度**：黄铜色在所有背景下都可见
- **绝不移除**：对键盘导航至关重要
- **光环偏移**：使用背景色进行清晰区分

### 动效偏好：
- 遵循 `prefers-reduced-motion` 媒体查询
- 禁用或大幅减少过渡持续时间
- 在无动效的情况下保持功能

### 语义化 HTML：
- 使用正确的标题层级
- 使用 `<nav>`， `<main>`， `<footer>` 等语义标签
- 使用 `<button>` 表示操作， `<a>` 表示导航
- 为纯图标按钮使用 `aria-label`

### 屏幕阅读器考量：
- 装饰元素应有 `aria-hidden="true"`
- 图片必须有描述性的 alt 文本
- 表单输入框必须有相关联的标签
- 焦点顺序必须符合逻辑

### 技术栈：
- **CSS 框架**：Tailwind CSS v4+，使用任意值语法 `[#C9A962]`

- 固定叠加层使用单个元素，而非每个组件一个

- 最少化自定义字体至三个家族
- 为 Google Fonts 使用 font-display: swap

- 现代浏览器

## 总结

学术/古典风格由其**材质真实感**（做旧纸张、深色木材、抛光黄铜）、**卓越的排版**（三种不同的衬线字体，各有其用）和**标志性的建筑元素**（拱顶、角落装饰、罗马数字）所定义。

当每个元素都感觉像是存在于一个19世纪的大学图书馆中时，这种风格就成功了。当它感觉像是一个随意套上衬线字体的通用深色主题时，它就失败了。

黄铜/金色强调色是交互语言。复古到彩色的过渡是魔法时刻。拱顶图片是建筑签名。它们共同创造了一个 cohesive、prestigious、scholarly 的体验，感觉 timeless 和 trustworthy。
