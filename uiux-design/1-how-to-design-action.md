# 设计实战

以个人和OPC网站设计为例。

## 以下面流程重新组织提示词

### 1 理解需求

> 用户是谁？
> 目标是什么？
> 业务目标是什么？
> 使用场景？
### 2 要展示的内容

> 必须展示什么？
> 什么是核心？什么是辅助？
> 信息优先级是什么？
### 3 组织内容架构和操作流

> 分几个页面？
> 页面以及元素间怎么跳转？
> 用户从哪里进来？怎么走？哪里可能卡住？
### 4 设计页面结构和UX

> 通过低保真实现具体的页面结构？以及页面元素跳转方式
### 5 设计页面表现层（UI）

> 加入视觉元素：
> 怎么排版？
> 层级设置？
> 元素间留多大空间？
> 怎么做色彩搭配？
> 动效怎么设计？

## 新版提示词

```markdown
# 网站需求

## 简介

我是一个独立开发者，办了一家OPC(One Person Company)，这个网站作为我个人以及公司的门户网站。

## 需求梳理

+ 用户是谁？
  希望了解我的潜在合作者，比如一些有技术外包需求、需要数字转型的小微企业以及小工作室、甚至是在组建团队的创业者。
+ 目标是什么？
  作为展示自己（技能、资质、作品）的窗口，提供自己的联系方式，寻求更多的合作机会。

## 设计页面结构和UX

+ 头部标题栏
  固定在顶部展示。
  包括下面内容：
  + 页面标题（左部展示）
    （不同页面标题内容不同）
    + 首页/手记/阅读/生活页面都展示我的英文名字“Arvin Lee”
    + OPC页面展示一人公司名字“库赛科”
  + Tab栏（居中展示）
    显示几个页面的切换按钮，点击对应按钮切换到对应的页面
  + “联系我”按钮（右边展示）
    点击“联系我”按钮，弹窗展示我的邮箱、微信号，以及对应的二维码
  + “编辑”按钮（右边展示）
    点击后，输入密码认证，认证通过后，直接内联对当前页面内容进行编辑。

+ 内容区
  （内容区每个页面的展示内容不同）
  
  + 首页
    分为下面几个部分：
    + 首屏内容（Hero区域）
      分左右两部分：
      + 左边
        + 标题：Hi，我是 Arvin Lee
        + 副标题：一个工作多年的Web全栈程序员，现在从事独立开发，创办了自己的OPC，在做一些自己的产品，实现一些有趣有价值的想法。
        + 如果你有想法，却没有技术背景，请联系我！
	    + 按钮：联系我
      + 右边
        + 轮播图
          展示一组图片：商务合作、代码开发、项目上线、HappyEnding。
    + 提供服务
      + 服务能力
        卡片式展示。
        + 全栈架构设计与开发
	    + AI应用开发
	    + 产品设计
	    + DevOps
	    + 技术咨询 
      + 技术栈 
        一排技术的Logo，慢慢循环滚动。
    + 个人作品
      + 卡片式展示（图片 + 描述 + 技术标签）
    + 成长历程
      + 时间轴倒序展示
        + 标题行：标题 - 年月
        + 描述
    + 近期动态 
      列表的形式展示最近在做什么
  
  + OPC
	+ Hero（首屏）
	  + 布局	
		左（6）｜右（6） 或 居中布局
	  + 左侧内容结构	
		+ 标签（可选）
		  深圳市库赛科技术有限公司
		+ 主标题（核心）
		  让您的想法转化为可落地的产品
		+ 副标题（价值）
		  致力于为个人、传统企业、创业者打造高质量数字产品；从产品设计到开发落地，帮助你把想法变成产品
		+ CTA按钮
		  [ 开始合作 ] [ 查看案例 ]
		  点击跳转到对应的部分。
	  + 右侧视觉建议
	    + 产品 UI 拼图
		  + 项目卡片堆叠
		  + 轻动效展示		
    + Trust（信任背书）
	  + 布局
		+ 横向条 / 网格
	    + 内容方式
		  + 数据
			10+ 项目交付
			5+ 年经验
			100% 客户满意
		  + 客户类型
			服务对象：
			创业团队 / 企业 / 内容创作者
		  + 客户评价
			“帮助我们从0搭建产品体系...”
	+ Services（服务能力）
	  + 布局	
	    + 标题
	    + 副标题（可选）
	    + 卡片 grid（3列）
		  + 卡片结构
		    + 图标
		    + 标题
		    + 一句话描述
		  + 卡片示例
		    + case 1:
			  全栈开发
			  从架构到上线一体化交付
		    + case 2:
			  AI应用开发
			  构建智能产品
		    + case 3:
			  产品设计
			  体验驱动设计
		    + case 4:
			  DevOps
			  自动化部署
		    + case 5:
			  技术咨询
			  技术决策支持
	  + 层级	
		标题 > 卡片标题 > 描述
	+ Case Studies（案例）
	  + 布局	
	    + 标题
		+ 项目 grid（2-3列）
		+ 卡片结构
		  + 图片
		  + 标题
		  + 行业标签
		  + 一句话说明
	  + 详情页建议
		+ 问题
		+ 解决方案
		+ 结果
		+ 技术方案
	+ CTA（转化区）
	  + 布局
		+ 居中大区块
	  + 内容	
		准备开始你的项目了吗？
		[ 联系我 ]
	  + 设计
		+ 对比强
		+ 简洁
		+ 明确行动

  + 手记
    + 极简博客风格
    + 按时间倒序排列
    + 每条内容：标题 + 日期 + 简短内容（展示不超过两行）
    + 分页展示
    + 支持打标签
    + 支持按照内容和标签搜索 
    + 支持新建手记、在线修改
    + 手记详情页
      + 展示内容
        + 标题
        + 日期 + 标签
        + 完整正文

  + 阅读
    + 布局
      + 标题
	  + 描述
	    带着目的读当前阶段需要读的书！
	  + 书籍分类
	    每个分类单独占据一行
	    此分类中的书籍横向排列，展示书籍封面，可以左右滑动
	    分类：
	    + 工具
	    + 哲学
	    + 宗教
	    + 心理
	    + 人际
	    + 政经史
	    + 艺术
	  + 支持创建分类、上传书籍、删除书籍
	  + 点击书籍可以阅读

  + 生活
    布局、内容等自由发挥吧
    - 分类
	  - 音乐
	  - 电影
	  - 饮食
	  - 运动
	  - 游戏
	  - 摄影
	- 每个分类都需要支持添加修改删除项目
+ 尾部
  不固定在底部，多列展示
  第一列：
  标题行：头像+“ArvinLee”
  另起一行展示“独立开发者 · Web全栈工程师”
  第二列：
  标题行：展示“联系方式”
  列举邮箱和微信号
  第三列：
  社交账号外链，比如 Github、微信公众号、B站，点击跳转到对应的账号主页

## 设计页面表现层（UI）

各个页面的表现层内容，让 AI 自己发挥，页面风格设计参考模版的设计风格。
```
