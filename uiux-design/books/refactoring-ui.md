# 重构 UI

- 从零开始
	- 从功能开始而不是布局
	- 在设计一个新功能的最早阶段，最重要的是别陷在字体、阴影、图标这类底层细节的取舍上，先别上色，细节留到以后再说
	- 不要过度设计（不要加还没准备好实现的功能）
	- 选择一种个性
		- 字体选择
			- 想要优雅或经典的外观，可以在设计中加入衬线字体
			- 想要俏皮感，用圆润的无衬线字体就行
			- 如果你追求更朴素的外观，或想靠其他元素来定调，中性无衬线字体是很不错的选择
		- 颜色
			（色彩心理学）
		- 边框圆角
			- 小圆角相当中性，本身传达不出什么强烈的个性
			- 大圆角则开始显得俏皮起来
			- 而完全不用圆角，会显得更严肃、更正式
			- 无论选哪种，保持一致都很重要。同一界面里方角和圆角混着用，几乎总比坚持只用一种更难看。
		- 语言
			- 用更客观、更少个人色彩的语气，会显得更官方、更专业
			- 而使用更友好、更随意的用语，则会让网站显得，嗯，更友好
		- 明确你真正想要什么
			- 可以参考想触达的人群平时使用的其他网站
	- 限制你的选择
		- 提前定义系统
			- 选择一组颜色
			- 定好一套严格的字体等级
			- 当你被限定在一组受限值里做设计时，决策会轻松得多，因为“正确”选项一下少了很多
		- 系统中的因素
			(每引入一个因素就引入一套针对这个因素的新系统，避免后面重复决定)
			- 字号
			- 字重
			- 行高
			- 颜色
			- 外边距
			- 内边距
			- 宽度
			- 高度
			- 盒子阴影
			- 边框圆角
			- 边框宽度
			- 不透明度
			- ......
- 层级关系就是一切
	- 视觉层级说的是界面里各个元素在彼此之间的重要程度。它是你手里最有用的“设计感”神器
	- 刻意弱化那些次要的、三级的信息，同时下功夫把最重要的元素突出出来
	- 突出层级关系的方法
		- 不要光靠字号去堆层级，字重、颜色是更好的选择
		- 界面设计里，常备两种字重就够用了：
			一种常规字重（400或500，具体看字体），用于大部分正文
			对你想强调的文本，用更粗的字重（600 或 700）
		- 想用更浅的字重来弱化某些文字，不如改用更浅的颜色或更小的字号
		- 别在彩色背景上用灰字
			挑一个色相一致（比如绿色和青色）的，再调饱和度和明度，直到看着舒服为止
		- 可以靠弱化其他元素来强化目标元素
			比如缩减字重、字号、颜色调的更柔和；如果侧边栏感觉在跟主内容区抢风头，那就别给它背景色——让内容直接落在页面背景上就好
	- 除了表单其他许多情况下根本不需要标签（“标签：值”格式）
		- 单看格式就能认出这是什么数据时不要使用标签
		- 即使某条数据离开标签后并不完全明确，你也常常可以通过给值补充说明性文字，来避免添加标签，比如：别写“库存：12”，试试“还剩12件”之类的说法
		- 如果存在多条相似的数据，必需使用标签也应该让标签变得更小、降低对比度、采用更轻的字重，或三者结合，以此来弱化它的存在感
	- 将视觉层次和文档层次分离
		- 不要像文档那样使用 h1 h2 h3 这样的标题标签，章节标题更像标签，而不是真正的“标题”——它们是辅助性内容，不应抢走所有注意力
			通常，章节里的内容才是焦点，而不是标题；
			绝大多数情况下，标题其实应该做得相当小：极端一点，你甚至可以在标记中出于无障碍考虑保留章节标题，但在视觉上完全隐藏它们
		- 平衡图标的重量与对比度
			一个图标如果太过突出，可以给它换上更柔和的颜色降低对比度；
			可以调整列表中条目间的边界线的宽度、颜色、透明度来增强隔离或减弱割裂感
	- 语义是次要的
		- 大多数页面只有一个真正的主操作，几个次要操作，以及少数偶尔用到的第三级操作；设计这些操作时，必须清晰地传达它们在层次中的位置
		- 主操作应当一目了然。饱和度高、对比度强的纯色背景在这里效果极佳；对于次级操作则要弱化它们的层次感
			次操作应当清楚可见，但不抢镜。描边样式或低对比度背景色都是不错的选择
			第三级操作应当可被发现，但不打扰。像处理链接那样去设计它们，通常是最合适的做法
			当你以层次优先的思路来设计页面操作时，最终得到的 UI 会少很多杂乱感，表意也更加清晰
		- 破坏性操作
			具有破坏性或高严重性的元素如果不是页面主操作也最好使用次级或第三级的按钮样式来呈现
- 布局与间距
	- 从一开始就预留大量留白
		先给某个元素远远过量的空间，再一点一点地削减，直到你对最终效果感到满意为止
	- 紧凑的UI也有他的用武之地：比方说，你在设计某种仪表盘，需要一屏之内展现海量信息
	- 建立一套间距与尺寸系统
		应该把自己限制在一套预先定义好的、有限的值集合里
	- 你不必填满整个屏幕
		没必要因为某个元素（比如导航栏）是全宽的，就让所有东西都跟着做成全宽
		- 缩小画布
			在宽大的画布上设计一个小界面时，可以把画布缩小
		- 用“列”来思考
			如果你设计的某个部分在较窄宽度下效果最好，可放进整体偏宽的界面里又显得失衡，那就看看能不能把它拆成多列，而不是一味加宽
			如果你既想更好地利用可用空间，又不想让表单更难用，可以把辅助说明文字拆到单独一列
		- 不要强求
			就像你不必担心填满整个屏幕一样，你也没必要非把所有东西都塞进一块小地方
	- 网格被高估了
		除非你确实想让它按比例缩放，否则别用百分比来给元素定尺寸
		没必要就别缩小元素，比如登录卡片，空间足够时就设置一个最大尺寸，只有当屏幕宽度小于这个最大尺寸时才让它收缩
	- 相对尺寸不好缩放
	- 避免模凌两可的间距
		每当你靠间距来连接一组元素时，始终确保组周围的空间大于组内部的空间
- 设计文本
	- 建立字体比例系统
		- 模块化缩放
			最务实的做法就是直接手动取值，比如手动选取一组字体大小比例：12px、14px、16px、18px、20px、24px、30px、36px
			避开使用 em 单位
	- 选用优质字体
		对于UI设计而言，最稳妥的选择往往是一款相当中性的无衬线字体——比如像Helvetica那样的经典之作
		另一个绝佳选择是干脆依赖系统字体栈
		忽略那些字重不足五种的选择
		许多字体目录（如 Google Fonts）都支持按「样式数量」筛选——它是可用字重数与对应斜体变体的总和
		优化易读性：界面正文里，避开那些x高度偏低的窄体字
		相信大众的眼光，选择流行的字体
		拆解几个你喜欢的网站，看看它们都用了哪些字体
		一旦你开始留意优秀网站上的排版细节，用不了多久，你就能相当自然地判断一款字体是好是坏了
	- 控制好行宽
		排段落时，太容易犯的错就是让文字迁就布局，而不是先去想怎么给出最好的阅读体验
		为了获得最佳阅读体验，要保证每行能放下 45–75 个字符（这里说的英文字符）
		当段落文字与图片或其他大组件混排时，即便整个内容区必须加宽才能容纳那些元素，段落本身的宽度也要照旧限制，比如左右留白，多列展示
	- 按基线对齐，而非居中
		一行里面字号不同的文字应该按基线对齐而非居中对齐
	- 行高与字号要成比例
		窄内容可搭配较短行高（如1.5），宽内容则可能需要高达2的行高
		行高与字号成反比——小字号应配更大的行高，大字号则配更小的行高
	- 并非每个链接都需要颜色
		对于页面上满是链接元素，使用那种专为让正文链接“跳出来”而设计的处理，就会显得过分抢眼，令人不适
		这时多数链接不妨用更微妙的方式强调，比如仅靠加粗或加深颜色
		如果链接不在主要操作路径上还可以考虑只在悬停时加下划线或变色
	- 对齐时以可读性为先
		长文本不要文字剧中对齐，应该于书写方向一致，比如多使用左对齐
		短文本（不超过两三行）可以使用剧中对齐
		设计包含数字的表格时，请将数字右对齐，当一列数字的小数点都处在同一位置时，扫一眼就能轻松比较
		两端对齐文本在印刷品中效果出众；在网页上想营造更正式外观时也很适用。但若不加小心，它会在词与词之间制造大量难看的空隙
	- 善用字距
		一般来说，应当信任字体设计师，别去动字间距。话虽如此，有几种常见情况通过调整字间距确实能改善设计
		- 为标题收紧字间距
			如果你想把一款字间距偏宽的字体家族用在标题上，通常应当减小字间距，去模仿专用标题字体那种紧凑外观
		- 提高全大写文本的可读性
			给全大写文本适当增加字距，往往能显著提升可读性
- 色彩的运用
	- 抛弃十六进制，改用HSL
		（但是实际还是十六进制使用居多）
	- 你需要的颜色比你想象的更多
		一个好的调色板可以拆成三类：灰色、主色和强调色
		- 灰色
			文本、背景、面板、表单控件——界面里几乎一切都是灰色的
			实际使用中，你需要8到10种灰色可供挑选
			纯黑色往往显得很不自然，所以从一个非常深的灰色开始，再均匀地一路过渡到白色
		- 主色
			大多数网站需要一种，或许两种颜色，用于主要操作、活动导航元素等。这些颜色决定了整个网站给人的第一印象——正是它们让你一看到Facebook就想到“蓝”
			和灰色一样，你需要多种深浅不同的色调（5-10种）供选择
			极浅的色调可以用来做提示信息之类的着色背景，较深的色调则非常适合用于文字
		- 强调色
			除了主色，每个网站还需要一些强调色，用来向用户传达不同的信息
			比如，你可以用黄色、粉色或青色这样抢眼的颜色来突出一个新功能：
			- 用红色来确认一个破坏性操作
			- 用黄色来提示警告信息
			- 用绿色来凸显积极的趋势
			- ......
			这些颜色你同样需要准备多个色调，即便它们在整个界面中应该用得相当克制
	- 预先定义好你的色调
		应当在一开始就定下一组固定的色阶，便于你在实际工作中从容挑选
		如何为每种颜色选定色调：
		- 先选好基础色，即中间的色阶，再向亮色和暗色两边展开
		- 一种颜色的最深色阶通常留给文本，而最浅的色阶则常用来给元素背景着色
	- 别让亮度扼杀了饱和度
		在 HSL 色彩空间中，当颜色亮度逼近 0% 或 100% 时，饱和度的影响会被大幅削弱
		如果你不想让某种颜色的亮色和暗色显得灰扑扑的，就得在亮度偏离 50% 时相应地提高饱和度
		善用感知亮度
		通过旋转色相来改变亮度（比直接调整亮度更好用）
		- 想让颜色变亮，就把色相朝最近的亮色相旋转——60°、180°或300°
		- 想让颜色变暗，就把色相朝最近的暗色相旋转——0°、120°或240°
		（在HSL（色相、饱和度、明度）色彩模型中，色相就是颜色在色环上的位置，用0°到360°的角度表示。而旋转色相，就是把这个角度值增加或减少一定的度数，把颜色沿色环“拨动”到另一个位置，这种方法虽然能在不牺牲颜色强度的前提下改变亮度，但最好小幅度使用。色相旋转不要超过20°到30°，否则就会变成一种完全不同的颜色，而不只是更亮或更暗）
		当然，你也可以把两种方法组合起来：一部分亮度来自色相，一部分来自亮度
	- 灰色不一定要灰
		可以给灰色增加饱和度：
		- 想让灰色显得冷，就掺一点蓝色：想让灰色显得暖，就加一点黄色或橙色
	- 无障碍不等于丑
		为了保证设计的无障碍性，Web内容无障碍指南（WCAG）建议：普通文本（约18px以下）的对比度至少为4.5:1，较大文本的对比度至少为3:1
		- 翻转对比度
			不在深色背景上用浅色文本，改用浅色背景上的深色文本
		- 旋转色调
			深色面板中的次要文字挑选颜色时，如果不逼近纯白，很难达到推荐的对比度，但是又不想让主文本（纯白色）和次文本看起来一个样，在不靠近白色的前提下提高对比度，一个办法就是把色调转向更亮的颜色，比如青色、品红或黄色
	- 不要只依赖颜色
		颜色是强化信息、帮助理解的绝佳工具，但要小心别完全依赖它——否则色盲用户会很难看懂你的界面，可以用其他方式把同样的信息表达出来，比如加图标表示正向或负向变化
- 创造深度
	- 模拟光源
		通过模拟光源照射物体表面形成的亮暗差别实现，比如使用阴影
	- 用阴影传达高度
		- 按钮这类元素，用较小的阴影就很合适——你希望它被注意到，但又不想让它喧宾夺主
		- 中等阴影则适合下拉菜单之类的元素，这些组件需要在界面中稍微“抬高”一点，和周围的内容拉开距离
		- 大阴影最适合模态对话框，这时候你要的就是牢牢抓住用户的全部注意力
		- 提前建立一套高度系统
			先定义最小和最大的阴影，然后用大小近乎线性递增的阴影填充中间部分
		- 你也可以通过改用更小的阴影，或干脆彻底移除阴影，让按钮在点击时仿佛被压入页面，产生一种被按下的真实感
	- 阴影可以分为两部分
		第一层阴影更大更柔和，带着显著的垂直偏移和较大的模糊半径。它模仿的是直接光源在物体后方投射的阴影
		第二层阴影更为紧致深邃，垂直偏移更小，模糊半径也更小。它模拟的是物体下方的阴蔽区域，那些连环境光都难以触及的地方
	- 扁平设计也能有深度
	- 让元素重叠，形成层次
		创造深度最有效的途径之一，是让不同元素互相重叠，让设计呈现出多层结构的感觉
		你也可以让某个元素比父级更高，这样它就能在两侧同时产生重叠
- 图片处理
	- 用好图片
		如果你的需求较为通用，外面有大量优质资源可以买到出色图库照片。甚至还有 Unsplash 这样的网站，免费提供绝美图片
		无论如何，别拿占位图做设计，然后指望事后用手机拍两张照片替换上去。这从来行不通
	- 文字需要始终如一的对比度
		把标题压在一张巨型主视觉图上，结果不管文字用什么颜色，依然很难看清，这时的解决方法：
		- 可以叠加一层覆盖物，降低图片的明暗落差，让文字与背景的对比度保持稳定
		- 调低图片的对比度
		- 为图片着色
		- 给文字加阴影
		黑色覆盖物会压暗亮部，让浅色文字跳出来；白色覆盖物则会提亮暗部，帮助深色文字立足
	- 每样东西都有它应有的设计尺寸
		- 别放大/缩小图标
			如果手头只有小图标，不妨把它们装进另一个形状里，再给这个形状加上背景色
		- 别缩小截图
	- 当心用户上传的内容
		- 使用统一的宽高比展示用户上传的图片
		- 当用户提供的图片背景色与UI背景接近时，图片和背景会融在一起，图片的轮廓也随之消失，不要指望用边框来解决，试试加一层微妙的内阴影
- 收尾润色
	- 让默认样式超常发挥
		- 比如将项目符号列表的符号换成图标
		- 如果你正在做推荐语，可以试着把引号“升级”成视觉元素——调大字号、换个颜色。链接也是做特殊样式的好帮手：你可以只改改颜色和字重，也可以玩得更花哨，比如加一条粗而多彩的自定义下划线，让它和文字微微交叠
	- 用强调色边框添上色彩
		- ……或者用来凸显当前激活的导航项
		- ……或者放在一条警告消息的侧边
		- ……或者在标题下方压上短短一条
		- ……甚至横跨整个版面的顶部
	- 给背景加点装饰
		- 换个背景色
			- 让背景更有活力的一个办法，就是简单地换掉颜色，这招适合用来突出某个独立的面板，也能让不同页面区块之间区分得更清楚
			- 想要更有动感，你甚至可以用一点轻微的渐变：为求最佳效果，两种颜色之间的色相夹角不要超过约 30°
		- 用重复图案
		- 加个简单的形状或插图
	- 别忽略空状态
	- 少用边框
		- 当需要在两个元素之间制造分隔时，尽量克制住想也不想就加边框的冲动，边框用得太多了，设计会显得拥挤又杂乱
		- 更好的方法：
			- 使用盒阴影
			- 使用两种不同的浅色背景颜色
			- 增加额外间距
	- 跳出框框思考
		- 比如下拉菜单只是一个浮动框像怎么设计都行，可以拆成几个区块、用多栏排版，加上辅助文字或彩色图标——怎么有趣怎么来
		- 表格也一样，不需要和数据库表一样展示，对于某列用不着排序完全可以和相关列合并，整理出更有趣的层级关系
		- 比如一组单选按钮，如果在页面中举足轻重，不妨改用可选择的卡片
- 升级进阶
	- 去找那些你不会做的设计决策
	- 重建你最喜欢的界面
